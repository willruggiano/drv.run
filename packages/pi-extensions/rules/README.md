# Path rules extension

This `pi` extension enables auto-loading [rules], including support for
path-scoped rules.

## Usage

Add [rules] files to `.agents/rules/` and they will be autoloaded by this
extension. For example, upon firing up `pi` in this repository:

```pi
 Loaded 6 rules from .agents/rules (3 global, 3 scoped)
```

[rules]:
  https://code.claude.com/docs/en/memory#organize-rules-with-claude/rules/
